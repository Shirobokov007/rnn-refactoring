# Рекуррентная нейронная сеть (RNN) для генерации текста

## О проекте
Реализация рекуррентной нейронной сети (RNN) с нуля на NumPy для генерации текста.  
Модель обучается на символьном уровне предсказывать следующий символ в последовательности.

## Что было улучшено (рефакторинг)

### По заданию (обязательные изменения)
| Требование | Было | Стало |
|------------|------|-------|
| Размер токена | One-hot (каждый символ) | Embedding (32-мерные векторы) |
| Размер текста | "hello world!" (~12 символов) | ~5000 символов (стихотворение/книга) |
| Скрытые слои | 1 слой (hidden_size=10) | 2 слоя + embedding (hidden_size=128) |

### Дополнительные улучшения
-  Использование NumPy для векторизации
-  Embedding слой вместо one-hot кодирования
-  Параметр температуры для управления разнообразием генерации
-  BPTT (Backpropagation Through Time)
-  Загрузка текста из интернета/локального файла
-  Docstrings и type hints
-  Разделение на классы и методы
